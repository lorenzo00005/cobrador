Cobrador is a Telegram agent for small Argentine sellers. Customers pay the way they already do, pesos by transfer through Ripio, and the agent settles every payment on Celo mainnet: wARS → USD₮, straight to the seller's wallet. No exchange, no manual conversion, no crypto knowledge.

How it works

The seller only talks to the agent in Spanish on Telegram. Everything that moves money runs in deterministic code, triggered by on-chain events.

Charge

The seller says what they sold and for how much. The agent registers the sale and returns a Ripio payment link (or the seller's own CVU via the Ripio Ramps API).

Customer pays

The customer pays pesos through Ripio. Ripio converts them to wARS and delivers them to the agent wallet on Celo.

Settle

The agent detects the wARS, takes an RFQ quote on Textile FX, swaps wARS → USD₮ and sends the USD₮ to the seller. Gas is paid in USD₮.

Report

"✅ Payment received for product", then a reply "💸 Sent to your wallet" with Celoscan links.

Guardrails

An agent that moves someone's money has to be boring in the right places.

  • Owner only. The Telegram channel ignores every chat except the seller's.
  • Money moves in code, never by chat. Settlement runs on payment events; tools that move or redirect funds need an explicit confirmation button.
  • No hallucinated numbers. Payment and settlement messages are fixed templates with real amounts and hashes.
  • Idempotent. A duplicated event never swaps twice. Per-settlement cap and a USD₮ gas buffer so the final transfer never reverts.
  • Prompt-injection aware. Event data is treated as data, never as instructions.
